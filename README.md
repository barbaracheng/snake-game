# 🐍 贪吃蛇游戏

一个精美、响应式的贪吃蛇游戏，支持移动端和 PC 端。

## ✨ 特性

- 🎮 **经典玩法** - 传统的贪吃蛇游戏体验
- 🎨 **精美界面** - 现代化 UI 设计，渐变色彩
- 📱 **响应式设计** - 完美适配手机、平板和桌面
- 🎯 **移动端优化** - 支持触控按钮和滑动操作
- ⌨️ **键盘控制** - 支持方向键和 WASD
- 💾 **最高分记录** - 本地存储最高分
- ⚡ **动态难度** - 随着得分增加游戏速度加快
- 🌐 **PWA 就绪** - 可安装为移动应用

## 🎮 如何游玩

### PC 端
- 使用 **方向键** 或 **WASD** 控制蛇的方向
- 避免撞墙和撞到自己
- 吃掉食物（苹果）获得分数

### 移动端
- 点击屏幕上的 **方向按钮**
- 或者在游戏区域 **滑动** 手势控制

## 🛠️ 本地运行

1. 克隆仓库：
```bash
git clone https://github.com/yourusername/snake-game.git
cd snake-game
```

2. 直接打开 `index.html` 文件，或者使用本地服务器：

```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Node.js
npx serve
```

3. 在浏览器中访问 `http://localhost:8000`

## 📱 安装为 PWA

1. 在移动设备上打开游戏
2. 点击浏览器菜单 → "添加到主屏幕" 或 "安装应用"
3. 现在可以像原生应用一样启动游戏！

## 🏗️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式和动画
- **JavaScript (ES6+)** - 游戏逻辑
- **Canvas API** - 渲染游戏画面

## 🎨 游戏特色

- **渐变背景** - 深色主题，护眼舒适
- **蛇身动画** - 身体渐变效果，头部有眼睛
- **食物特效** - 发光的苹果，有阴影效果
- **平滑控制** - 防止快速输入导致的反向移动
- **触摸优化** - 防止页面滚动，提供良好的移动体验

## 📊 分数系统

- 每吃一个食物：+10 分
- 游戏速度随分数增加
- 最高分自动保存到本地存储

## 🔧 自定义

可以在 `game.js` 中修改以下参数：

```javascript
this.gridSize = 20;        // 网格大小
this.canvasSize = 400;      // 画布大小
this.speed = 150;          // 初始速度 (毫秒)
```
